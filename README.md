# Create Custom Agents with Copilot Studio — Hands-On Lab

A self-contained, interactive lab guide for building custom agents with Microsoft Copilot Studio. Designed for beginner-level workshop participants.

## View the Lab

👉 **[Open Lab Guide](https://sunelt13.github.io/copilot-studio-lab1/)**

## What You'll Build

Participants create a custom Copilot Studio agent from scratch, covering:

- Setting up a Copilot Studio environment
- Creating an agent with knowledge sources
- Adding topics and conversation flows
- Integrating Adaptive Cards
- Connecting agent flows (Power Automate)
- Publishing to Microsoft Teams

## Format

- Self-contained single HTML file — no dependencies
- Step-by-step instructions with expandable exercises
- Screenshots and visual guidance throughout
- Dark/light theme support
- Mobile-responsive layout

## Usage

Open the GitHub Pages link above, or clone and open `index.html` locally in any browser.

```bash
git clone https://github.com/sunelt13/copilot-studio-lab1.git
open index.html
```
